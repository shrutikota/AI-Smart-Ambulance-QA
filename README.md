# AI-Smart-Ambulance-QA

## Smart Ambulance Traffic Clearance System

### Project Overview

The Smart Ambulance Traffic Clearance System is an embedded system designed to provide traffic priority to an emergency ambulance.

The system uses an ambulance unit and a traffic signal unit. The ambulance unit provides location and emergency information, while the traffic signal unit processes the information and controls the traffic signal indicators.

### Main Components

- ESP32 DevKit
- NEO-6M GPS Module
- Red LED
- Yellow LED
- Green LED
- Active Buzzer

### Main Working

Ambulance Unit
↓
GPS and Emergency Information
↓
Wireless Communication
↓
Traffic Signal Unit
↓
Traffic Signal Priority
↓
Green LED + Buzzer
